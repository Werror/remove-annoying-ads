# remove-annoying-ads

Userscripts that remove ads and payment/upgrade prompts from free websites, so they're safe and pleasant for kids to use.

## Scripts

| Site | Script | Install |
|------|--------|---------|
| [Ratatype](https://www.ratatype.com/) | [ratatype/](ratatype/) | [Install](https://raw.githubusercontent.com/Werror/remove-annoying-ads/main/ratatype/ratatype-kidsafe.user.js) |

## How to install

1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. Click a script's **Install** link above; Tampermonkey opens an install page. Click **Install**.
3. Reload the site.

Scripts include `@updateURL`, so Tampermonkey picks up new versions automatically.

## Adding a site

Create a folder named after the site with a `<site>-*.user.js` script and a README, then add a row to the table above.
